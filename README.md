# 🇬🇧 English

## About the Project

PhishGuard AI is a cybersecurity application designed to help users identify suspicious emails, SMS messages, and potentially dangerous links.

The project aims to increase cybersecurity awareness by detecting common phishing indicators and providing understandable explanations of potential threats.

## Key Features

- **Phishing Detection:** Identifies suspicious patterns in messages.
- **URL Analysis:** Detects potentially unsafe URL characteristics.
- **Risk Assessment:** Classifies messages by risk level.
- **Threat Explanation:** Explains why a message may be dangerous.
- **User-Friendly Interface:** Simple web interface built with Streamlit.
- **Free & Pro Plans:** Basic analysis is available in the Free interface. Pro features are under development.

## Technologies Used

- Python
- Streamlit
- Pytest
- Git & GitHub
- Rule-Based Security Analysis

## Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/Gunay0/phishguard-ai.git
cd phishguard-ai
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run the Application

```bash
python -m streamlit run ui/app.py
```

## Run Automated Tests

```bash
python -m pytest -v
```

## Current Project Status

The phishing detection prototype is functional and has successfully passed 9 automated tests.

AI-powered analysis, payment processing, and Pro subscriptions are planned features and are not currently active.
